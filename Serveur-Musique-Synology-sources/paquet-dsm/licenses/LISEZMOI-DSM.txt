SERVEUR MUSIQUE 0.0.6 pour Synology (x86_64, DSM 7.2, ex. DS220+)
=================================================================

Même programme que le paquet QNAP 0.0.6 (ohscrobbler, licence MIT),
compilé pour processeur Intel/AMD 64 bits. Fonctions identiques : serveur
de musique « Musique NAS » (port 49494, événements 49495), suivi des écoutes
pour Last.fm, page de configuration http://<adresse-du-NAS>:8790/.
Aucun composant tiers : su-exec et musl du paquet QNAP ne servent pas ici,
DSM lance lui-même le programme sous le compte du paquet.

Installation
------------
1. Centre de paquets > Installation manuelle > choisir le fichier .spk.
   Le paquet n'est pas signé : DSM affiche un avertissement « éditeur
   inconnu », confirmer pour continuer.
2. Donner la lecture du dossier musique au compte du paquet :
   Panneau de configuration > Dossier partagé > (dossier de la musique,
   ex. « music ») > Modifier > Permissions > liste « Utilisateur interne du
   système » > MusiqueServeur > cocher « Lecture seule » > Enregistrer.
   Sans cela, DSM interdit au paquet de lire la musique.
3. Ouvrir la page (bouton « Ouvrir » du Centre de paquets, ou
   http://<adresse-du-NAS>:8790/), choisir le dossier musique dans
   Réglages > Serveur de musique, puis redémarrer le serveur depuis la page.
4. Si le pare-feu de DSM est activé : autoriser les ports TCP 8790, 49494,
   49495 et UDP 1900 (Panneau de configuration > Sécurité > Pare-feu).

Réglages : /var/packages/MusiqueServeur/var/musique.conf
--------------------------------------------------------
Créé au premier démarrage. Après modification : arrêter puis exécuter le
paquet dans le Centre de paquets.
  SHARES       racine des dossiers partagés (défaut : /volume1). Le dossier
               musique choisi sur la page doit être dessous.
  MUSIC_DIR    dossier de la musique (détecté : /volume1/music…).
  SERVER_NAME  nom diffusé (défaut : Musique NAS), modifiable sur la page.
  INTERFACE    carte réseau ; vide = celle de la route par défaut.
  UDN_SERVEUR  identifiant UPnP du serveur, à ne pas modifier.

Données (conservées lors d'une mise à jour) : /var/packages/MusiqueServeur/var
  scrobbler/  réglages de la page (config.json), écoutes, compte Last.fm
  cache/      index, pochettes, photos (peut être supprimé : reconstruit)
  logs/       journal du serveur ; etat/ : état et journal du superviseur

Last.fm : clé API et secret à coller uniquement sur la page :8790
(https://www.last.fm/api/account/create pour les créer).
